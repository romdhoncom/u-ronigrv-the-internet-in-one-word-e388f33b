The internet, in one word: **receipts**. The whole internet is a courtroom where the only currency is screenshots — every claim, every drama, every argument ends with somebody posting them.

## Run it

```sh
node main.ts
```

This writes the word to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
